# Visual System — Canonical A2

归属：[Product Master Plan 1.2](../HCL_ASSISTANT_PRODUCT_MASTER_PLAN.md) 与 [UX Spec](UX_SPEC.md)。本文件采用已经确认的 Review 参数，不开启新视觉方向；是待实现规格，不代表当前页面已经符合。

## 1. 方向

安静、清楚、以阅读为中心的轻量编辑器式 AI 界面。极简、成熟、克制；不靠科技蓝、发光、渐变、大量卡片或不断运动的认知图谱表现 AI。差异化来自回答、连续理解、变化呈现与一致细节。

## 2. Typography

使用系统无衬线，中文优先系统中文字体；不为品牌感强加大字体依赖。统一正文、引用、代码、表格与列表排版，不把所有输出留在普通p标签样式中。

| 用途 | 起始规格 |
|---|---|
| 回答正文 | 16px / 27–28px line-height |
| Composer | 16px / 24–26px |
| 侧栏与控件 | 14px / 20px |
| 次级说明 | 12–13px / 18–20px |
| 对话标题 | 16–18px，中等字重 |
| 页面标题 | 22–26px，克制使用 |
| 代码 | 14–15px，等宽，独立横向滚动 |

不靠每行加粗建立层级，不把重要隐私说明压成10–11px。颜色与字重辅助结构，不替代明确文本。

## 3. Spacing 与布局

4px基础尺度；主要间距8/12/16/24/32/48px。Sidebar约248px，顶栏52–56px，消息列常态约760px，消息组间距28–36px，Explain380–420px，主区域水平留白不低于24px。Composer与消息列对齐，不横跨窗口。

打开详细检查时优先折叠导航或切换布局，不把聊天/导航/图谱挤成三窄栏。较窄窗口侧栏为抽屉；移动端Explain/Inspector为全屏视图。所有尺寸是待视口/缩放/无障碍测试的tokens，不是固定截图坐标。

## 4. Sidebar 与消息

侧栏为新对话、搜索、最近对话、按需项目，底部记忆与设置；当前项仅轻微底色/字重，不给每条历史描边卡片。默认保存不逐条标“已保存”，只提示未保存、失败或临时。

助手消息采用开放阅读区域，不放大卡片；用户短消息的浅底色随内容合理收缩，不撑成宽彩条。长文本与文件避免多层卡片嵌套。引用靠近引用处；操作低权重但键盘和触屏可发现。流式滚动不得干扰用户向上阅读。

## 5. Composer

初始约两行，随内容增长，最多约六至八行；取消手动拉伸角标与无意义大空白。附件一个入口，选中文件后显示条目、读取状态和错误；限制在相关动作时解释。发送/停止位置稳定，失败保留草稿与焦点。中文输入法确认候选不能误发送。快捷键说明不占据主placeholder。

## 6. 颜色 tokens

| 角色 | 建议值 |
|---|---|
| 主背景 | #FAFAF8 |
| 侧栏 | #F3F3F0 |
| 表面/输入 | #FFFFFF |
| 主文字 | #222320 |
| 次级文字 | #646660 |
| 分隔线 | #E3E4DE |
| 少量强调 | #465B4C |
| 注意 | #8A5A18 |
| 错误/破坏性操作 | #B33A32 |

这是起始色板，不是认知正确性编码。强调色不覆盖所有按钮和消息；绿色节点不表示结论为真。所有状态配文字，不能只依赖颜色。实现时校验正文对比度与非文本控件，不由色值存在推定达标。

## 7. Inspector 与 motion

Inspector白底、清晰分组、局部展开；支持、反证与执行顺序分开，不能全部用同一种箭头。JSON与全图仅技术详情。

一般转换120–180ms；侧栏180–220ms；支持减少动态效果。没有真实进度不播放深层认知分阶段动画，Judge不成为加载阶段。原则上不让动效改变阅读位置。

## 8. 验收

验证桌面与窄窗口、中文组合输入、键盘/焦点、缩放、对比度、触控目标、减少动态效果和流式滚动。重要动作建议约44px命中区域。截图不替代真实交互、恢复与数据测试。不得通过移走环境说明隐藏mock；不得以视觉完成升级研究效力。
