# GitHub Pages synthetic preview

Public preview URL:

`https://haohongfei2001-png.github.io/hcl-assistant/`

This surface is intentionally narrower than the local L2 product:

- browser-only static HTML/CSS/JavaScript;
- no Python API, SQLite service, SSE backend, provider transport or real HCL runtime;
- no research repository, confirmation material, LongMemEval, protected artifacts or credentials;
- no server-side account, authentication or persistence;
- preview state is stored only in the visitor's browser `localStorage`;
- only synthetic/scripted interactions are represented;
- arbitrary text is not evidence of general semantic understanding.

The preview exists only to make the adopted Assistant / Explain / Lab interaction easy to inspect. It does not change `STOP_WITH_HANDOFF_L3_GATED`, authorize L3, or establish HCL efficacy.

Do not enter real private data. Use the local L2 application for the full provider-free Controller/SQLite behavior and CI-backed acceptance surface.
