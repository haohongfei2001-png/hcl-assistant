## Scope and provenance

All five adopted PNG payloads and their SVG storage wrappers are unchanged. The shared CSS and native SVG companion components are identifiable implementation derivatives. Both M-01 orb and M-02 receiver remain available alongside Off; selected_companion remains null. ## Candidate behavior

- Selecting a TXT/Markdown file stages it locally; explicit submit performs the existing registration path. Failure preserves the pending file, navigation isolates it, successful reset clears it.
- File labels are projected only from currently allowed source metadata, never duplicated into stored local runs. Stop/delete suppress them.
- Desktop evidence and source share one connected context surface; source replacement preserves the evidence list scroll. Mobile uses a full-height modal with native focus containment.
- Reading return records the semantic trigger/paragraph, offset, focus and valid selection. Intentional reading cancels automated restoration; explicit Return uses the original anchor.
- Both companions expose only actual busy activity and support Off, reduced motion and opaque fallback. Suggestions populate a draft and never send automatically.

## Acceptance evidence pending

A hosted browser run must supply real screenshots at the adopted desktop size and narrow layouts, source/revision replay artifacts, anchor measurements, console/layout assertions and reduced-motion/opaque checks. The reviewer must compare actual app regions against the unchanged originals. Screenshots represent synthetic product UI acceptance, not real-provider browser acceptance or HCL efficacy. No screenshot, computed token or passing checker alone certifies the visual design.
